| P0 · 停止任务 | [聊天拦截](D:/bot/插件/任务模式/astrbot_plugin_agent_lab/main.py:841)只认精确短语；本地复现「停止任务」「结束任务」「停止当前任务！」都未命中，「停止当前任务」「任务终止」能命中。日常聊天会过滤 `agent_lab_finish`；后台虽然有该工具，但只能按完成条件收尾，不能代替管理员取消。 | 在进入模型前识别明确的管理员指令，容忍常见短语和句末标点；聊天和 WebUI 共用终止入口。停止与按现状交付分别处理；立即禁止新派发、作废待执行审批，记录仍在途或结果未知的操作。不要让模型自行取得管理员终止权。 |

| P1 · 画布全局 | [「全局」抽屉](D:/bot/插件/任务模式/astrbot_plugin_agent_lab/pages/agent-lab/app.js:4670)写的是整个方案的提示词、技能及插件覆盖，而非当前节点。黑名单勾选写入 `plugin_overrides=false`，取消勾选不清旧值；保存时 `AgentSpec` 不保留 `plugin_blacklist` 字段，已复现回读不同步。现有[工具过滤](D:/bot/插件/任务模式/astrbot_plugin_agent_lab/main.py:9237)仍拦截宿主全局停用的普通插件，本次未证实越过宿主权限。 | 迁到画布外的「方案设置 → 规则与权限」，标明作用范围和生效时机。画布只编辑流程与节点，最多进一步收紧；管理员端使用单一可回读字段，后端拒绝节点或模型扩大权限，不能只靠隐藏选项。 |
