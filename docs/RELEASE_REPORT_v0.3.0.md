# Agent Lab v0.3.0 更新报告

2026-11-23。六项改动一起发布，真实 Bot 使用体验由小莫验收。

| 改动 | 行为 |
| --- | --- |
| 完全权限 | 授权范围内目录查询、搜索、建目录、普通文件读写、Shell/Python 与常规测试直接执行；少量明确文件及限定后缀的临时文件清理不因删除标签送审。标准开发、只读档保持原规则。 |
| 主动审批 | 完全权限下，兜底拒绝不会自动建审批卡或冻结整个任务。主 Agent 可调整方案，或用确切工具及参数主动申请；显式人工节点、任务计划和用户另行设置的审批规则继续有效。 |
| 授权范围 | 管理员路径优先；未配置时使用已批准的计划范围，计划常规修订不能扩大授权。权限保存后同步当前任务，正在执行的工具先收尾，后续调用按新版本检查。累计预算不重置，项目预算仍用于新任务。 |
| 审批续跑 | 最近证据包含调用参数、状态、审批 ID 与结果；完整脱敏输出独立保存，超长可按证据 ID 分页读取。紧接着重发刚完成的同一审批调用会返回已有结果，不再次派发；失败或未知结果不复用为成功。 |
| 停止与交付 | 支持“停止任务”“结束任务”“停止当前任务！”等直接指令，接受常见标点。日常控制工具只执行管理员当前明确指令；停止/交付沿用先写终止标记的管理员入口，不受未完成步骤或待审批阻挡。 |
| 独立方案设置 | 画布“全局”移到画布外的“方案设置”，预案列表也有入口；保存提示词、技能和插件禁用。禁用开关使用持久字段，取消勾选可回读；宿主停用插件不能在这里启用。方案设置用于新任务，项目权限用于当前任务。 |

兜底识别显式范围外路径、清空项目/目录、无限定批量删除、超过20个明确删除目标、常见破坏性数据库/磁盘操作、敏感凭证路径及管理员明确审批线。普通 `rm -f a.tmp b.tmp`、限定后缀的临时文件清理不等同于清空项目。Shell/Python 的任意动态代码不能靠文本分析完整证明安全；宿主原生操作系统/沙箱权限仍承担实际隔离，本版没有新建沙箱，也不扩大宿主原有权限。

升级时，完全权限下旧版“执行前风险检查”生成的待审批批次会作废；AI 主动申请的审批保留。插件重载后，原运行任务仍需管理员核对记录并恢复；不会自动重跑结果未知的操作。

重复危险尝试有独立上限：同一执行步骤前两次被拒绝时，模型可纠正或主动申请；累计第3次拒绝就暂停自动执行并发送状态说明，不创建审批。换参数、换危险路径、插入普通查询不会清零；拒绝尝试也计入工具预算。管理员明确恢复、更新权限，或执行已批准的操作后可重新开始；既有时间、步数、Token 预算和无进展检测继续有效。
