# v0.2.6 验证报告

本轮实际运行了浏览器和后端检查。测试使用临时数据与模拟平台对象，不代表完整生产实例已经联调。

| 项目 | 结果 |
| --- | --- |
| Edge iframe 交互 | 56/56 |
| 后端模块/Quart/临时文件 | 19/19 |
| 连线路由 | 6种场景，30/30断言 |
| 静态契约 | 10/10 |
| 1440/1100/820 截图 | 无横向溢出，素材搜索框可命中 |
| JS/CSS 解析 | 通过 |
| 生产 AstrBot/真实模型 | 未启动 |

新增后端用例覆盖：已启用实例过滤、默认机器人保存/重新读取、简报开关和间隔、同一任务消息线的进展/反问/审批、管理员停止抢先于发送回写、发送失败不重发、消息记录独立于任务检查点。

新增浏览器用例覆盖：只有真实实例可选、双击默认、iframe reload 后默认恢复、任务消息设置保存、画布侧栏与项目侧栏几何一致、后端能力素材可见、定时/心跳素材不新增、任务消息时间线展示。

收尾检查额外抓到并修复了：顶部保存漏存节点编辑草稿、记录JSON格式错误被静默吞掉、WebUI归档后通知丢失原管理员、直接审批工具没有写入统一消息线、超长计划挤掉批准/拒绝命令。失效默认回退、发送期间清理不重建文件也已覆盖。

项目页三处辅助文字的计算对比度约6.11:1，高于4.5:1门槛；实际画布线条为不透明深蓝灰2.6px，悬停/选中3.2px。没有把这三处抽样宣称为全站无障碍审计。

最终性能样本只用于比较：首次项目显示约189ms，24次拖动及150ms settle约330ms，整组场景一个约99ms长任务。长任务由宿主与iframe的观察器汇总，页面重载不会清空已采集结果。未声称稳定60FPS，也未做大规模任务/节点压测。

最终自评：页面对齐9.0、文字可读性8.8、黑白绿一致性8.8、动效与稳定性8.7、画布连线8.6、任务消息可理解性8.8，综合8.8/10。自评依据为截图和自动化结果，仍需要用户在真实 AstrBot iframe 中做手感验收。

保留原工具栏和408px素材窗几何；窄窗口同时展开侧栏、素材窗时，可见画布必然减少，需要使用原收起入口。避障是有界候选路由，不保证任意重叠节点图都无交叉。真实平台主动投递、实际模型执行与生产部署兼容性仍未端到端验证。
