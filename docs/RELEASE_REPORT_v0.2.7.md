# Agent Lab v0.2.7 更新报告

日期：2026-11-21。适配基线：AstrBot 4.29.4。插件名称、ID、目录及 `/al` 入口保持兼容。

## 原问题与处理

| 问题 | v0.2.7 的处理 |
|---|---|
| 无画布也要进画布才能调任务预算 | 项目页「运行设置」集中设置预算、档位、范围、风险线和任务指引；暂停任务可在详情调总额度。旧节点不再设置任务总预算或提升权限。 |
| 任务工具上限与原生设置不对齐 | 两处使用同一个 AstrBot 会话配置档的 `agent_runner.config.misc.max_steps`。项目保存走 AstrBot 配置保存接口；新一轮读取原生值。共用一档的会话共享上限。 |
| 探路按工具名一律审批 | 已识别的常规结构化读写、只读 shell 和常规测试可继续执行。范围外普通操作合并提醒并留痕。不能判定影响的任意脚本仍会送审。 |
| 批准后重新生成参数，原批准挂空 | 批次保存操作和准确参数，批准后在下一轮模型推理前续接。批准绑定当前步骤、计划和输入修订；过时批次失效。派发及证据进任务记录，未知结果须核对。 |
| 要复制英文命令和 ID | 用当前 Bot 模型生成中文审批摘要，原管理员可回复「批准」或「拒绝」处理唯一待批项；含多项或摘要异常时仍可在详情核对。 |
| 拒绝后不知道怎么退出或续跑 | 「任务暂停」「任务终止」「任务状态」「任务继续」「任务重启」接入同一管理入口；检查点续接不会恢复已拒绝的同一动作。 |
| 预算耗尽冒充仍在工作 | 优先显示真实暂停原因，提供 80% 提醒和总量停机通知；每轮超额转为续轮，达到总量暂停。模型的一次返回可能跨过限额，下一次请求或工具不会继续派发。 |
| 任务提示太长；同一工具日志只见证据 | 用身份锚点代替日常 Persona 全文，减少历史窗口并保留完整工具调用组；工具正文、错误和审计证据同条返回。 |
| 本地 shell 类显示未注册 | 按 AstrBot 本地执行器的方式构造本地 shell，并按来源会话选运行环境。日志中的事件循环延迟尚未在实际机器复测。 |

## 验证范围

- 临时存储与 Quart 后端测试：覆盖原生配置档双向同步、零预算语义、任务调额、范围外只读、中文审批、批次按原参数续接、拒绝、证据配对与预算停机消息。
- Edge 插件 iframe：验证项目设置保存与读回、多行范围、原有项目导航、任务与画布交互；三个窗口尺寸和六个路由场景已检查。
- 模拟使用真实插件的状态和桥接代码，替换模型、工具、平台发信及 AstrBot 配置对象。未连接生产 Bot 或改动线上配置。实际 token 降幅、私聊投递和事件循环延迟仍需线上记录验证。

## 升级

升级前先暂停执行中的任务。原先方案预算可作为兼容默认值；本轮起使用项目设置，已有任务的额度以任务页为准。旧版依赖工具名整类放行的审批配置不再授权危险动作；旧审批执行前请重新提交具体批次。完全访问扩大可用工具范围，仍保留宿主权限限制与高危审批。
