# Workflow Material Rework Plan

本计划用于本轮工作流素材、触发入口、Agent 编排、API 范围和节点编辑器改造。旧的画布总计划与审计草稿不再作为实施依据。

## 目标

- 消除入口触发配置重复，确保每类触发素材只负责自己的触发来源。
- 将子 Agent 从全局抽屉/工具按钮改为可拖入画布的 Agent 角色素材。
- 将 Agent 协作类节点从普通计划分支中拆出，形成独立素材分类。
- 将 API 的“一次调用”和“作用范围”分开表达，让 API 影响范围在画布上可见。
- 将便签类节点改为会影响后续执行的提示注入节点，避免无效素材。
- 收紧高级编辑器，减少普通用户可见的无效字段。
- 保持修改范围只围绕插件功能，不引入无关脚本、宣传文案或外部网址。

## 批次 1：后端语义与数据模型

- 明确触发来源边界：
  - `listen_message` 只承接消息、命令、暗号、关键词、正则和自然语言入口。
  - `schedule_trigger` 只承接定时入口。
  - `plugin_event_trigger` 只承接插件事件入口。
  - `webhook_trigger` 只承接 Webhook 入口。
- 为插件事件入口补齐插件来源、事件名列表、payload 输出变量和匹配语义。
- 为定时入口补齐 cron、时区、错峰和定时 payload 语义。
- 将 `note` 的运行语义调整为提示注入类节点，或新增 `prompt_inject` 并迁移旧 `note` 模板。
- 建立 Agent 角色块的后端字段约定：
  - 名称、颜色、模型 provider、工具范围、并发上限、限速、角色提示词。
  - 输入/输出端口。
  - 领地范围以节点 `owner` 为权威。
- 建立 API 范围块字段约定：
  - 绑定 API、作用范围、输出变量、默认调用约束。
  - 与 `call_api` 的一次调用行为区分。

## 批次 2：运行时与保存归一化

- 保存方案时由入口素材节点归一化生成 `workflow_trigger`，不再依赖入口编辑器中的重复表单。
- 加载旧方案时，将旧 `workflow_trigger` 的消息、定时、插件事件和 webhook 配置迁移到对应入口节点。
- 修复 `agent_message` 缺少目标时仍继续推进的问题，缺目标应阻塞并停在当前节点。
- 修复子 Agent 工具范围计算：
  - 方案工具为空时，子 Agent 工具范围直接生效。
  - 方案工具非空时，子 Agent 工具范围受方案工具白名单约束。
- Agent 角色块与 `SubAgentSpec` 双向同步：
  - 画布上的 Agent 角色块是可见配置入口。
  - `AgentSpec.sub_agents` 是持久化结构。
- API 范围块与节点执行上下文同步，使被框选节点能读取范围默认 API 配置。

## 批次 3：校验与诊断

- 工作流静态检查增加以下规则：
  - 消息入口不得配置定时、插件事件或 webhook 字段。
  - 插件事件入口必须绑定插件来源或事件名。
  - 定时入口必须有 cron。
  - Agent 领地 `owner` 必须指向存在的 Agent 角色。
  - API 范围块必须绑定有效 API。
  - 提示注入节点必须有输入点、输出点和注入文本。
- 抽屉或报告中的 Agent 领地计数改为根据节点 `owner` 实时计算，不再依赖 `member_node_ids` 缓存。
- 高级字段保留为开发调试用途，普通检查报告不鼓励依赖无效字段。

## 批次 4：前端素材库与画布交互

前端改造放在最后执行，等后端语义稳定后统一接入。

- 删除右侧工具条中的子 Agent 注册按钮。
- 删除框选工具条中的子 Agent 指派按钮。
- 新增素材分类 `Agent 编排`：
  - 主 Agent。
  - 注册新 Agent。
  - 已注册子 Agent 素材。
  - 任务分配。
  - 报告整理。
  - 意见传达。
  - 事项讨论。
  - 汇总决策。
- 新增或调整素材分类 `数据与模板`：
  - 设置变量。
  - 读取变量。
  - 文本模板。
  - JSON 转换。
  - 合并数据。
  - 列表拆分或迭代准备。
- 触发类素材重新分工：
  - 消息监听入口编辑消息类触发。
  - 插件事件入口编辑插件来源与事件名。
  - 复杂定时入口编辑 cron。
  - Webhook 入口编辑路径与鉴权。
- Agent 角色块交互：
  - 卡片显示 Agent 名称、模型、颜色和工具范围摘要。
  - 编辑页配置模型、颜色、提示词、工具范围、并发和限速。
  - 卡片内提供领地选择按钮，点击后进入该 Agent 的领地框选模式。
  - Agent 角色块有输入/输出端口，可参与工作流连接。
- API 范围块交互：
  - 卡片显示 API 名称、方法和作用范围摘要。
  - 卡片内提供范围选择按钮。
  - 被范围覆盖的节点显示 API 角标或边框。
- 便签节点改为提示注入节点：
  - 补输入点和输出点。
  - 明确注入范围。
  - 运行时影响后续节点或 Agent。
- 高级编辑器改为开发调试区：
  - 默认只显示填空模式。
  - 高级区保留原始 JSON、端口、Schema、重试和超时。
  - 普通用户不直接编辑会破坏节点语义的基础字段。

## 验收

- 触发配置没有重复入口。
- 每个素材的职责可以从名称、编辑字段和连线结构看清楚。
- 子 Agent 和 API 范围都能在画布上可视化。
- 提示注入节点会实际影响后续执行。
- 高级编辑器不再制造普通用户不需要理解的无效字段。
- Python 编译与前端语法检查通过。
- 最终提交只包含插件相关代码与本计划文档。
