# v0.4.0 更新与验证报告

日期：2026-11-25。基于 v0.3.4 的核心执行层重构；实现说明见 [重构设计](REFACTOR_v0.4.0.md)。

## 使用效果

- Bot在完全权限的授权目录内读取、改代码、跑测试和清理少量指定文件直接工作。高危或越界先主动请示；兜底拒绝只退回动作，不自动替Bot发审批卡。
- 普通任务只增加五个控制工具：计划、进展、反问、请示、交付。任务清单允许边做边调整，完成一步不再强制停止当前工具循环。
- 删除120行读取代理、每请求历史折叠和证据ID回读。宿主读取范围原样传递；超32KiB结果在第一次返回时给出完整原文文件路径，后续历史保持不变。
- 交接只在真实容量压力或显式阶段切换时发生；先存原记录，再一次工作笔记。摘要超长平滑收尾，空返回或超时用最近完整工作窗口继续，不要求从头重读。
- 真实等价报错和高度重叠读取先提醒、持续无效才暂停；正常探索不因累计工具数量被截断。总Token、总耗时和管理员明确总调用预算继续生效。
- 审批、进展与最终正文由来源Bot自拟；最终交付不再调用另一个摘要模型改写。任务与日常仍使用独立Conversation，管理员停止、暂停和按现状交付优先。

## 实际代码变化

删除 `read_cache.py`、`context_views.py`、`agent_lab_read_tool_evidence`、计划二审函数与旧暗锁。技能说明由211行重写为40行。五个控制工具Schema为3192 UTF-8字节（含说明）。

从main拆出116个画布方法以及共用目录常量；main约从11419行降至5880行。画布执行保留为可选扩展，无画布任务不会拿到画布规章和旧控制工具。旧WebUI、项目存储和管理员入口保留。

整合审查另外修复：画布读取结构化工具错误而非匹配旧返回尾巴；模块目录常量完整导出；关闭提示注入时仍隔离日常控制工具；可选画布获得其提示所需工具；五工具实际出站Schema强制参数完整且不改宿主共享实例；自动交付期间的管理员暂停/停止和新输入不被旧结果覆盖。

Python编译、两份改动JS语法、存储/WebUI smoke、实际插件适配/画布mixin smoke及差异检查通过。新版替换了断言“120行以内/字符越少越好/模拟模型无条件成功”的旧测试，并迁移旧轮次熔断预期。适配器专项14项覆盖审查发现的六处问题。

## 边界与更新

所有量化数据为**离线状态驱动模拟**，使用真实本地文件/账本/桥接及子进程；没有调用线上语言模型、真实Bot或生产任务。不能据此宣称真实缓存命中率、节省百分比、TPM/线上延迟或保证小莫不再犯错。静态高危检查也不是任意脚本的操作系统沙箱。

此前持久保存的管理员预算与项目容量不会被擅自清空；默认无总调用限制只适用于新默认配置。旧项目如仍设有总工具预算，会明确继续生效，可在项目运行设置改为0不限。未知模型默认容量128k；管理员显式容量仍受已知宿主/模型上限约束。总耗时从任务创建起算，含等待审批和暂停。

更新插件后重载；已有执行任务会按原有恢复机制暂停，核对后继续。具体角色表现、真实任务流畅度和真实用量留给小莫体验，不替代实际验收。
